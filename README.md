# MeowMaze

**A Python Arcade Game | Processing**

A Pac-Man-inspired maze game built using Python and Processing. MeowMaze brings together custom-designed levels, interactive obstacles, and arcade-style mechanics in a three-level challenge.

Developed collaboratively with a focus on object-oriented programming, collision detection, and game-state management.

---

## Gameplay & Features

- **Progressive Difficulty** — Three maze levels with distinct layouts and increasing complexity.
- **Collision Mechanics** — Different obstacles trigger unique effects, from life reduction to movement disruption.
- **Scoring & Collectibles** — Collect fish, discover power-ups, and track progress.
- **Game-State Management** — Integrated lives, countdown timers, level transitions, and win/loss conditions.
- **Interactive Design** — Custom sprites, directional animations, sound effects, and keyboard-based controls.

## Technical Implementation

MeowMaze was developed using **Processing's Python Mode**, incorporating:

- **Object-Oriented Programming:** Modular classes for player entities, obstacles, collectibles, and game management.
- **Collision Detection:** Position-based algorithms governing player interactions with game elements.
- **Event-Driven Programming:** Keyboard input handling and frame-based game updates.
- **State Management:** Logic controlling player health, scores, timers, and level progression.

**Technologies:** `Python` · `Processing` · `OOP` · `Game Development`

## Getting Started

1. Download or clone this repository.
2. Install [Processing](https://processing.org/) with Python Mode.
3. Open `meowmaze.pyde` in Processing.
4. Keep the `images/` and `sounds/` directories alongside the main game file.
5. Configure the Minim audio library if required, then run the sketch.

**Controls:** Use the arrow keys to navigate the maze.
